## Abstract
Cognix is a personal knowledge operating system designed to give AI assistants a persistent, context-aware memory of a specific user. It addresses the limitations of session-only LLM assistants and basic RAG approaches by combining (1) memory ingestion and indexing, (2) concept relationship graphing, and (3) adaptive context compaction. The system aims to improve personalization accuracy, response relevance, and token efficiency by retrieving and compressing only the most relevant user knowledge for each query.
